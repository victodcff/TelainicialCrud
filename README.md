# 🐾 TelaInicialCrud

### Sistema de Gerenciamento com Autenticação

Aplicação desenvolvida em **ASP.NET Core MVC**, utilizando **C#**, **Entity Framework Core** e **ASP.NET Core Identity** para gerenciamento de usuários e autenticação.

---

# 📖 Sobre o Projeto

O **TelaInicialCrud** é um sistema desenvolvido em ASP.NET Core MVC com funcionalidades de CRUD e controle de acesso através do **ASP.NET Core Identity**.

O projeto utiliza o Entity Framework Core para o gerenciamento e persistência dos dados.

---

# 🚀 Funcionalidades

* ✅ Cadastro, edição e exclusão de registros
* ✅ Listagem de registros
* ✅ Sistema de autenticação
* ✅ Cadastro e gerenciamento de usuários
* ✅ Controle de acesso utilizando ASP.NET Core Identity

---

# 🛠 Tecnologias e Pacotes

* **Linguagem:** C#
* **Framework:** ASP.NET Core MVC
* **ORM:** Entity Framework Core
* **Autenticação:** ASP.NET Core Identity

---

# 🗄 Banco de Dados

O projeto utiliza **Entity Framework Core** com migrations para criação e atualização da estrutura do banco de dados.

Para aplicar as migrations, utilize:

```powershell
Update-Database
```

---

# 📁 Estrutura do Projeto

* **Areas/Identity** — páginas e recursos relacionados à autenticação e usuários
* **Controllers** — controladores da aplicação
* **Models** — modelos utilizados pelo sistema
* **Views** — páginas da aplicação
* **Migrations** — migrations do Entity Framework Core
* **wwwroot** — arquivos estáticos
* **Program.cs** — configuração e inicialização da aplicação

---

# ▶️ Como Executar

1. Clone o repositório.
2. Abra o projeto no **Visual Studio 2022**.
3. Configure a conexão com o banco de dados no `appsettings.json`.
4. Execute as migrations através do Package Manager Console:

```powershell
Update-Database
```

5. Execute o projeto pressionando **F5**.
